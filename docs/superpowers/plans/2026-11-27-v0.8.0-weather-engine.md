# v0.8.0 Weather Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One engine on US government sources that returns measured conditions, the official forecast, alerts, radar rain, sun and moon, each reading labelled with what it is and how old it is.

**Architecture:** New, additive modules beside the Open-Meteo loaders, which stay untouched and are marked deprecated. Pure parsers (units, conditions, grid intervals, radar pixels) are separate from thin fetchers; every fetcher goes through one transport with a fixed host list, the existing cache, and an optional consumer-supplied store for last-good readings.

**Tech Stack:** TypeScript 6, vitest 5, pnpm 10. No new dependency. Runs in browsers and Node 20+.

**Spec:** `docs/superpowers/specs/2026-11-27-one-weather-engine-design.md`. Requires `v0.7.0` merged first.

## Global Constraints

- The engine never throws to callers. A failure is `null` (or a stale reading inside its age bound).
- `onError` fires exactly once per ultimately-failed fetch, after the retry.
- A missing or `null` input is `null` out. Never `0`, never "clear", never "dry". An **absent key** is treated like `null`.
- Units out: °F, mph, inches, miles, feet, inHg. Times are epoch milliseconds.
- Hosts are constants: `https://api.weather.gov` and `https://mapservices.weather.noaa.gov`. No caller-supplied host.
- Every fetch takes `opts.fetchImpl`. Servers pass `opts.userAgent`; browsers omit it.
- Tests use the fixtures in `src/__tests__/fixtures/nws/` (recorded 2026-11-27T13:58Z for 41.03,-73.76) and `opts.now`. No test touches the network or the real clock.
- Outside NWS coverage (`/points` answers 404) every function returns `null` and `onError` does **not** fire.
- Zero runtime dependencies. `dist/` is committed with every `src/` change. No version bump until Task 11.
- Do not touch `.github/**`, `scripts/dependency-gate.mjs`, or `src/icons/**`.
- Before reporting a task done: `pnpm run check && pnpm run test && pnpm run build`, and `git status` shows no uncommitted `dist/` change.

## Review Focus

1. **An absent field.** The recorded observation has no `precipitationLastHour` key at all. Expect `precipLastHour: null`, no throw. (Task 6.)
2. **A re-gridded point.** A cached forecast URL that now answers 404 must evict the cached point and retry once with a fresh lookup. (Task 4; `evictPoint` comes from Task 2.)
3. **A dead or late station.** An observation older than 90 minutes, or with no temperature, must fall to the next station and then to the forecast hour, marked `forecast`. (Task 6.)
4. **Grid interval edges.** `PT1H`, `PT6H` and `P6DT15H` durations; a block whose value is `null`; an hour exactly at a block's end, which belongs to the next block. (Task 4.)
5. **A rate limit.** HTTP 429 or 5xx serves the last good reading only inside its age bound and marks it `stale`; past the bound the answer is `null`. `onError` fires once. (Task 3.)

