# v0.7.0 Nullable Weather Code Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A missing Open-Meteo weather code is reported as `null` (unknown), never as `0` (clear sky).

**Architecture:** The four Open-Meteo loaders stop defaulting `weather_code` to `0`. The code, its icon key and its description become nullable together, through one new pure helper. No icon component changes (the icons shipped in v0.6.0; this is the engine half of that split).

**Tech Stack:** TypeScript 6, vitest 5, pnpm 10. No new dependency.

**Spec:** `docs/superpowers/specs/2026-11-27-one-weather-engine-design.md` (Releases table, row `v0.7.0`) and `CLAUDE.md` §3 rule 2.

## Global Constraints

- Measurements are `number | null`; a missing value is never fabricated as `0`.
- The engine never throws to callers. `onError` fires exactly once per ultimately-failed fetch.
- `dist/` is committed: change `src/` → `pnpm build` → commit `dist/` in the same commit.
- Version `0.7.0` is a **breaking** change shipped as a 0.x minor. Call it breaking.
- Never add `[release-approved]` to a commit. The owner grants it at merge.
- Do not touch `.github/**`, `scripts/dependency-gate.mjs`, or anything under `src/icons/`.
- Before reporting done: `pnpm run check && pnpm run test && pnpm run build`, then `git status` shows no uncommitted `dist/` change.

## Review Focus

1. **A code of `0` that Open-Meteo really sent** must stay `0` / "Clear sky" / `clear`. The fix must not turn real clear sky into unknown. (Task 1, test 1.)
2. **A non-numeric code** (`"3"`, `NaN`, `null`) must be `null`, not coerced. (Task 1, test 2.)
3. **A number that is not a WMO code** (for example `4`) keeps its number but gets `icon: null` and `description: null`, not a fabricated "partly cloudy". (Task 1, test 3.)
4. **The event path:** a `null` code on the matched hour must not break the forecast strip or the warning flags, which read rain and wind, not the code. (Task 1, test 5.)
5. **Existing callers of `getWeatherInfo(code: number)`** keep today's behaviour exactly. (Task 1, test 4.)

- [ ] **Step 1: Write the failing tests** in `src/__tests__/nullableCode.test.ts`. Stub the network with `opts.fetchImpl`, as `src/__tests__/current.test.ts` does. Clear each loader's cache in `beforeEach`.

```ts
// 1. a real 0 stays clear sky
it("keeps a real code 0 as clear sky", async () => {
  // current payload with current.weather_code = 0
  expect(r.weatherCode).toBe(0); expect(r.icon).toBe("clear"); expect(r.description).toBe("Clear sky");
});
// 2. missing / null / non-numeric code is unknown
it.each([undefined, null, "3", NaN])("reports code %s as unknown", async (code) => {
  // current payload with current.weather_code = code
  expect(r.weatherCode).toBeNull(); expect(r.icon).toBeNull(); expect(r.description).toBeNull();
});
// 3. a number that is not a WMO code keeps its number, with no icon
it("does not invent an icon for a non-WMO number", async () => {
  // current payload with current.weather_code = 4
  expect(r.weatherCode).toBe(4); expect(r.icon).toBeNull(); expect(r.description).toBeNull();
});
// 4. the pure helpers
it("weatherInfoOrNull", () => {
  expect(weatherInfoOrNull(null)).toBeNull(); expect(weatherInfoOrNull(undefined)).toBeNull();
  expect(weatherInfoOrNull(4)).toBeNull(); expect(weatherInfoOrNull(3)).toEqual({ description: "Overcast", icon: "overcast" });
  expect(getWeatherInfo(4)).toEqual({ description: "Unknown", icon: "partly-cloudy" }); // legacy, unchanged
});
// 5. hourly, daily and the event path
it("hourly: a null entry and a missing array are both unknown", async () => {
  // hourly.weather_code = [0, null] -> hours[0].weatherCode 0, hours[1].weatherCode null
  // hourly without weather_code -> every hour's weatherCode null
});
it("daily: a null code gives null icon and description", async () => {
  // daily.weather_code = [null] -> days[0] weatherCode/icon/description all null
});
it("event: a null code keeps the flags and the strip working", async () => {
  // matched hour: weather_code null, precipitation_probability 80, wind_gusts_10m 50
  expect(ev.weatherCode).toBeNull(); expect(ev.icon).toBeNull(); expect(ev.description).toBeNull();
  expect(ev.isRainWarning).toBe(true); expect(ev.isSevereWarning).toBe(true);
  expect(ev.forecastStrip.every((s) => s.icon === null)).toBe(true);
});
```
